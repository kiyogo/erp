# Tiến độ sửa và hoàn thiện web cũ

Ngày cập nhật: 2026-10-28. Phạm vi yêu cầu: toàn bộ tính năng hiện tại và đối chiếu video 0426.mp4 + văn bản người dùng. Chưa hoàn thành toàn bộ phạm vi này.

Giữ React/custom UI, Node HTTP, collections API, PostgreSQL/SQLite và Canvas editor. Không xóa menu, module hay dữ liệu hiện tại. Các thay đổi đã có trước trong KTable, smart-table, package files, Vite và dự án Rust được giữ nguyên.

## Mốc báo cáo hiện tại

- Workbook audit liệt kê 29 ứng dụng trong video; audit source ban đầu thấy code liên quan ở 22 ứng dụng và chưa thấy app tương đương ở 7 ứng dụng. Đây là độ phủ source ban đầu, không phải tỷ lệ chức năng đã hoàn thành.
- Sheet tổng quan ghi 973 gạch đầu dòng. Sheet chi tiết hiện đánh số liên tục 1–982 vì đã bổ sung 9 luồng; dùng 982 làm tổng checklist hiện có.
- Chưa có phần trăm hoàn thành toàn web đáng tin cậy vì 982 mục chưa được đối chiếu lại từng mục bằng runtime evidence. Bảng tiến độ bên dưới theo dõi luồng, không thay thế checklist từng mục.
- Mốc kiểm thử mới nhất ngày 2026-10-28: 107 API test, 117 web/domain test; 38 checkpoint PostgreSQL đạt ở lần chạy trước; typecheck, production build và API syntax check đạt. Trình duyệt đã chạy luồng cấp phát/xác nhận/thu hồi, sửa chữa/duyệt/chờ linh kiện/tiếp tục/nghiệm thu, bảo trì/checklist/nghiệm thu, điều chuyển, một luồng thanh lý bán, workflow bổ sung, thanh toán nhân viên → duyệt/ghi sổ/từ chối, khấu hao ba phương pháp, tạm ứng tạo/cấp/quyết toán và Phòng họp thiết lập/tạo phòng/đặt/hủy với dữ liệu thử riêng. Build hiện tại tạo bundle JavaScript 4,908.23 kB và vẫn cảnh báo chunk lớn hơn 500 kB.

Xác nhận xóa dữ liệu là khai báo của người dùng, hệ thống không tự kiểm tra thiết bị; giá thu là số ghi trong hồ sơ, chưa đối chiếu giao dịch ngân hàng/két; kết quả lãi/lỗ nội bộ chưa tạo bút toán Sổ Cái.
- Nhiệm vụ tài sản ghi/xử lý qua API và PostgreSQL; nhân viên được chọn từ tài khoản đang hoạt động nhưng quyền thao tác hiện vẫn thuộc module quản trị/Admin, chưa có cổng tự cập nhật cho nhân viên. Chưa nghiệm thu UI trình duyệt.
- Công tác hiện lưu đề xuất, quyết định, chi phí và tệp chứng từ nội bộ; chưa đặt vé/khách sạn với nhà cung cấp, tạo khoản tạm ứng kế toán, ghi Sổ Cái, chuyển tiền hay ký CA. Quyết toán đã hoàn tất được khóa sửa trực tiếp; hiện chưa có luồng điều chỉnh/bút toán đảo.
- Chưa xem toàn bộ video từng khung hình; bảng đánh giá trước đó chỉ là nguồn đối chiếu sơ bộ.

## Tiếp tục theo yêu cầu gốc

1. Nghiệm thu các thao tác nghiệp vụ còn lại trên trình duyệt. Lượt rà production 246 route đã đạt nhưng không thay thế mọi nút và quy trình.
2. Hoàn thiện persistence/error handling của các caller `saveGenericData` còn lại, cache theo người dùng và chống ghi đè dữ liệu. Đã sửa phân trang và chặn late read ghi đè dữ liệu mới.
3. Tiếp tục phân quyền chi tiết/RBAC ngoài workflow, quản lý tài sản, kế toán/kho và tích hợp ký số CA/ngân hàng/thiết bị. Tài liệu scan/tải file gốc đã có kiểm thử riêng; chưa thay thế nghiệm thu mọi luồng gửi-ký-nhận.
4. Hoàn thiện quy chuẩn `asset_systems` trong quy trình: mã, thời hạn, vị trí, nhà cung cấp và gợi ý định mức đã được nối vào danh mục/cấp phát; tiếp tục xử lý ngoại lệ vượt định mức và nhập số dư khấu hao đầu kỳ.
5. Đối chiếu từng phần tử trong văn bản/video với UI → service → API → database, bổ sung chức năng thiếu trong module hiện có.
5. Viết/chạy kiểm thử nghiệp vụ, quyền, dữ liệu lỗi, tải lại trang và PostgreSQL cho từng luồng; cập nhật trạng thái theo bằng chứng.

## Lệnh kiểm tra

Trong `legacy/web`: `npm run typecheck`, `npm run build`, `npm test`.

Trong `legacy/api`: `node --check index.mjs`, `npm test`. `npm run test:postgres` là kiểm tra tự chọn, cần quyền tạo database thử; script chỉ tạo/xóa database có tên `kiyovn_codex_test_<uuid>` do chính lần chạy tạo.

Thử ghi Sổ Cái lương với dữ liệu riêng: trong `legacy/api` chạy `node tests/payroll-ledger-browser.mjs`.

Thử luồng bản quyền với dữ liệu riêng: trong `legacy/api` chạy `node tests/licenses-browser.mjs`.

Thử luồng cấp phát/thu hồi tài sản trên trình duyệt, kèm API SQLite và dữ liệu riêng: trong `legacy/api` chạy `node tests/asset-allocation-browser.mjs`.

Thử luồng sửa chữa tài sản trên trình duyệt, kèm API SQLite và dữ liệu riêng: trong `legacy/api` chạy `node tests/asset-repairs-browser.mjs`.

Thử luồng thanh lý tài sản trên trình duyệt, kèm API SQLite và dữ liệu riêng: trong `legacy/api` chạy `node tests/asset-disposal-browser.mjs`.

Thử luồng bảo trì tài sản trên trình duyệt, kèm API SQLite và dữ liệu riêng: trong `legacy/api` chạy `node tests/asset-maintenance-browser.mjs`.

Thử luồng workflow trên trình duyệt, kèm API SQLite và dữ liệu riêng: trong `legacy/api` chạy `node tests/workflow-browser.mjs`.

Thử luồng điểm và chương trình khuyến mại trên trình duyệt với API SQLite và web chạy riêng: trong `legacy/api` chạy `node tests/loyalty-browser.mjs`. Cần Chrome hoặc đặt `TEST_CHROME_PATH`; dữ liệu thử nằm trong thư mục tạm.

Thử luồng đề nghị thanh toán nhân viên, duyệt, ghi nhận chi vào sổ quỹ và từ chối trên trình duyệt với API SQLite riêng: trong `legacy/api` chạy `node tests/payments-browser.mjs`.

Thử thiết lập và ghi khấu hao theo cả ba phương pháp trên trình duyệt, đối chiếu tài sản/Sổ Cái và chống ghi trùng với API SQLite riêng: trong `legacy/api` chạy `node tests/asset-depreciation-browser.mjs`.

Thử tạo/cấp/quyết toán tạm ứng, kiểm tra số dư và tải lại bằng API SQLite riêng: trong `legacy/api` chạy `node tests/advances-browser.mjs`.

Thử lưu chính sách, tạo phòng, đặt/xem lịch/hủy và giữ lịch sử bằng API SQLite riêng: trong `legacy/api` chạy `node tests/meeting-rooms-browser.mjs`.

Kiểm tra route: cung cấp `TEST_EMAIL`, `TEST_PASSWORD` cho tài khoản được phép kiểm thử rồi chạy `node tests/browser-routes.mjs`. Có thể đặt `TEST_WEB_URL`, `TEST_API_URL`. Script không bấm nút thay đổi dữ liệu; kết quả ghi trong thư mục tạm hệ thống. Các test API dùng SQLite và kho file riêng trong thư mục tạm.
