# Bundled UI font

`NotoSans-Variable.ttf` is the Noto Sans variable font from the [Google Fonts Noto Sans repository](https://github.com/google/fonts/tree/main/ofl/notosans). The source family lists Vietnamese coverage. It is included unchanged under the SIL Open Font License 1.1; see `OFL.txt` in this directory.

SHA-256 of the bundled font: `BFB7BB691513F12E734DC346C03A03F784912432D7E3FA8E56EFCF906FE86B3D`.

The same font is embedded in the shared Rust UI for native and WebAssembly, so Vietnamese glyphs do not depend on Windows Segoe UI or the browser's system fonts.
